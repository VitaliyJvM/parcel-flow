Fonts bundled with the ParcelFlow web UI
========================================

Roboto
  Source:  @fontsource/roboto 5.3.0 (https://fontsource.org/fonts/roboto),
           from https://github.com/googlefonts/roboto-classic
  Files:   Latin and Latin Extended subsets, weights 400, 500, 700 (unmodified Fontsource files)
  License: SIL Open Font License 1.1 - see Roboto-OFL-1.1.txt

Material Symbols Outlined
  Source:  @fontsource-variable/material-symbols-outlined 5.3.9 (Google, Version 2.975),
           from https://github.com/google/material-design-icons
  Files:   material-symbols-outlined-subset.woff2 - a Modified Version: weight axis pinned at 400
           and reduced to the icons the application uses (see the web UI's
           scripts/subset-material-symbols.py). The license declares no Reserved Font Name.
  License: SIL Open Font License 1.1 - see MaterialSymbolsOutlined-OFL-1.1.txt
